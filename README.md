## Status

BTP-001 is **PROPOSED — NOT RATIFIED**. The external human-authority decision lives in `kcn-baseline-evidence` as `BTP-001-sign-off.md` with its detached signature and public key. This orientation repository contains no authority, no signatures, and no claims of its own.

## Recommended Reading Order

1. Read `BTP-001-sign-off.md` in `kcn-baseline-evidence` for the human decision and its status.
2. Switch to the `Python-3` branch of `kcn-btp001-report` and read `KCN_DOCTRINE.md`.
3. Consult `BTP-001-report-artifact-ledger.md` to see what files are present versus what was claimed.
4. Only then examine the benchmark report artifacts.
